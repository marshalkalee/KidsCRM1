Файл .xlsx с колонками (первая строка — заголовки, порядок колонок не важен):

  • ФИО ребёнка — обязательно
  • Дата рождения ребёнка — обязательно, ДД.ММ.ГГГГ (также понимает ДД/ММ/ГГГГ и ГГГГ-ММ-ДД)
  • Пол ребёнка — обязательно, М/Ж
  • ФИО родителя — обязательно (можно с ролью впереди, например «мама Иванова Марина»)
  • Телефон родителя — обязательно, можно несколько через запятую
  • Роль родителя — необязательно (мама/папа/опекун/бабушка)
  • Медицинские заметки — необязательно, переносится в карточку ребёнка
  • Остаток занятий — необязательно. Не создаёт абонемент автоматически, только попадает в отчёт после импорта для переноса вручную
