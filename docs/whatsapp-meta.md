# Подключение WhatsApp Cloud API

До получения реквизитов Meta интеграция работает в режиме `console`: шаблоны
считаются одобренными, сообщения пишутся в журнал и лог worker, внешней отправки
нет. Поэтому весь сценарий можно проверить заранее.

Для реального подключения нужны Business Portfolio и приложение Meta, WABA ID,
Phone number ID, постоянный access token системного пользователя и App Secret.
App Secret задаётся в `backend/.env` как `WHATSAPP_APP_SECRET`; остальные данные
владелец центра вводит в CRM на странице настроек рассылок. Токен обратно через
API не возвращается.

В Meta Webhooks указывается:

- callback: `https://<домен>/api/v1/messaging/whatsapp/webhook/`;
- verify token: показан в CRM после сохранения подключения;
- подписка на поле `messages`.

После подключения нужно нажать «Проверить подключение», затем
«Синхронизировать». Отправка разрешена только для шаблонов со статусом
`APPROVED`. Свободный текст доступен только 24 часа после входящего сообщения
родителя. Webhook-подпись `X-Hub-Signature-256` проверяется через App Secret.

Перед production-пуском:

1. Создать и одобрить в Meta шаблоны с именами `kidscrm_<event>_<language>`.
2. Проверить входящее сообщение, статусы `sent/delivered/read/failed` и STOP.
3. Выполнить пробную массовую отправку: предпросмотр должен показать получателей,
   причины пропуска, точное имя и текст шаблона.
4. Убедиться, что backend и worker используют один и тот же `.env`.
