# Кабинет родителя — правила доступа и API

Этап M4. Кабинет — отдельное приложение для родителей: свой вход по коду
(ADR-0007, TRU-135), свой токен, свои эндпоинты `/api/v1/portal/`. API
сотрудников токен родителя не принимает, кабинет не принимает JWT
сотрудника.

## Кто чьих детей видит (TRU-136)

Права берутся только из CRM, на каждом запросе. Ребёнок виден родителю,
если в карточке ребёнка есть контакт с номером родителя: в телефонах
контакта или в поле WhatsApp. Связи ищутся во всех активных центрах
платформы (`portal/access.py`).

| Случай | Решение |
|---|---|
| Мама и папа, каждый со своим номером, привязаны к одному ребёнку | Оба видят ребёнка, данные у обоих одинаковые. |
| Платит бабушка, в кабинет ходит мама | Важна связь контакта с ребёнком, а не роль. Плательщик и «просто контакт» видят одинаково: у обеих доступ, если обе привязаны к ребёнку. Кого не нужно пускать — того отвязывают в карточке ребёнка. |
| Ребёнок ушёл из центра | Ребёнок виден со статусом «ушёл», в конце списка, пока контакт привязан. Родитель может прийти за справкой или вернуться. Закрыть доступ — отвязать контакт. |
| Контакт отвязали или удалили родителя | Доступ пропадает сразу, на следующем запросе. Сессия может оставаться активной, но детей в ней нет. |
| Дети в разных филиалах или разных центрах | Один номер — один вход, видны все дети. У каждого ребёнка указан центр. |

## Что родитель может менять

- **Свой email** — меняется во всех его карточках «Родитель», запись в
  аудите центра.
- **Язык кабинета:** ru или kk.
- **Свой номер телефона.** Сначала код на **новый** номер, потом смена во
  всех его карточках; запись в аудите. Номер, который уже используется для
  входа, сам родитель не подставит — объединить два аккаунта может только
  администратор центра.
- **Данные ребёнка** — нет. Имя, дата рождения, группы, медицинские
  заметки меняются только у администратора.

## Что родитель видит о ребёнке

Имя, дата рождения и возраст, статус, фото, центр, филиалы, текущие группы
и направления. Не видит:
- медицинские заметки и причину ухода — их пишут сотрудники для себя;
- комментарии и коммуникации сотрудников;
- контакты других родителей.

Полный список полей согласуется с центром в TRU-141.

## API (`/api/v1/portal/`)

| Метод | Путь | Что |
|---|---|---|
| POST | `auth/request-code/` `{phone}` | Код на номер. Ответ одинаков для любого номера; 429 + `Retry-After` при лимите |
| POST | `auth/verify/` `{phone, code}` | `{token, expires_at}` |
| POST | `auth/logout/` `{everywhere?}` | Выход на этом устройстве или на всех |
| GET / DELETE | `auth/sessions/`, `auth/sessions/<id>/` | Устройства, отзыв |
| GET | `me/` | Профиль и все дети (`children[]`: id, full_name, birth_date, age, status, photo_url, organization, branches, groups) |
| GET | `children/<id>/` | Один ребёнок; чужой — 404 |
| GET / PATCH | `profile/` `{email?, language?}` | Профиль родителя |
| POST | `profile/phone/` `{phone}` → `{phone, code}` | Смена номера через код на новый номер |

Заголовок: `Authorization: Parent <token>`. Ошибки — `{detail}` с текстом
для родителя.

## Фронтенд кабинета (TRU-137) — как сделать экран

Кабинет живёт во frontend2 по адресу `/parent`, код — `frontend2/src/parent/`.
Это отдельное приложение: своя сессия (`ParentSession.jsx`), свой вход
(`ParentLogin.jsx`), свой API-клиент (`api.js`). CRM сотрудников оно не
подключает.

| Что | Где |
|---|---|
| Маршруты | `parent/ParentApp.jsx` |
| Вкладки внизу (телефон) и сверху (широкий экран) | `parent/nav.js` → `PARENT_NAV` |
| Шапка с выбором ребёнка, «нет связи», навигация | `parent/ParentLayout.jsx` |
| Кто вошёл, дети, выбранный ребёнок, выход | `useParent()` из `parent/useParent.js` |
| GET к API кабинета с сохранением на случай плохой связи | `usePortalData(url)` из `parent/api.js` |
| Произвольный запрос (POST и т.п.) | `portal` из `parent/api.js` — токен подставляется сам |

**Экран — это компонент в `parent/pages/`.** Шапка, отступы и навигация
уже есть, экран рисует только содержимое:

```jsx
import { CalendarDays } from 'lucide-react'
import { Card, EmptyState, ErrorState, Skeleton } from '../../ui'
import { t } from '../../i18n'
import { usePortalData } from '../api'
import { useParent } from '../useParent'

export default function ParentSchedule() {
  const { child } = useParent() // выбранный ребёнок, переключается в шапке
  const { data, loading, error, reload } = usePortalData(child && `children/${child.id}/schedule/`)
  if (loading && !data) return <Skeleton className="h-40" />
  if (error && !data) return <Card><ErrorState onRetry={reload} /></Card>
  if (!data?.length) return <Card><EmptyState icon={CalendarDays} title={t('Занятий пока нет')} /></Card>
  return null // содержимое экрана
}
```

- **Состояния.** Загрузка — `Skeleton`, нет данных — `EmptyState`,
  ошибка — `ErrorState`. «Нет связи» шапка показывает сама: без сети
  `usePortalData` отдаёт последние сохранённые данные (`stale`, `savedAt`).
  «Сессия истекла» — тоже сам кабинет: 401 уводит на вход.
- **Подключение.** Строка в `ParentApp.jsx`. Если экрану нужна вкладка —
  строка в `nav.js`. Сейчас на месте экранов TRU-138, 139, 142, 145
  стоят заглушки «скоро».
- **Сначала телефон.** Ширина 390 px без горизонтальной прокрутки; на
  широком экране та же колонка до 672 px.
- **Тексты — через `t()`**, переводы ru/kk (родитель выбирает язык в
  профиле).
- **Тон — для клиента, не для сотрудника.** «к оплате», а не
  «ЗАДОЛЖЕННОСТЬ»; «осталось 2 занятия, можно продлить» (TRU-138).
- **Эндпоинт экрана — в `backend/domains/people/portal/`.**
  - Класс `ParentView` (токен родителя).
  - Ребёнка проверять через `access.child_for_phone(request.user.phone, child_id)`:
    чужой и несуществующий неотличимы, 404.
  - Данные брать из сервисов CRM, не пересчитывать.

## Установка на телефон (PWA)

`public/parent/manifest.json`, иконки `public/parent/icon-*.png`,
сервис-воркер `public/parent/sw.js` (scope `/parent/`). Сервис-воркер
кэширует только оболочку приложения: без сети кабинет открывается, а
данные берутся из сохранённого экраном. API он не кэширует.
Push-уведомления — V3, их можно добавить в тот же `sw.js`.

- **Android (Chrome):** меню → «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

Установка требует HTTPS; на `localhost` работает и без него.
