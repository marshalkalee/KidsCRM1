# Приёмка M3 «Аналитика» (TRU-129)

ТЗ раздел 9: этап заканчивается демо на реальных данных True Ballet и
приёмкой по чек-листу. Этот файл — чек-лист. Колонки «Результат» и
«Замечание» заполняются на демо; замечание, которое не исправить сразу,
переносится строкой в `docs/project-status.md` («Нужно обсудить»).

Что уже проверено автотестами (`analytics/tests_dashboard.py`) на тестовых
данных: каждая плитка дашборда равна цифре своего экрана, права ролей на
всех отчётах M3, выгрузка каждого отчёта. На демо проверяем то же на
реальной базе и глазами.

**Как готовиться.** Период на дашборде — «Прошлый месяц» (у него закрыто
окно продления, цифры не «дозревают»). Филиал в шапке — «Все филиалы».
Дата демо, кто был: ______

## 2. Сквозная сверка с операционными экранами

| Плитка дашборда | С чем сверить | Как | Результат | Замечание |

| Задолженность (динамика) | — | «На конец прошлого периода» появляется только после ночных снимков; пусто в первый день — норма | | |
| Заполняемость групп | «Группы», колонка «Записано» | Сложить детей и места активных групп; «N детей на M мест» на плитке = эти суммы; «с недобором» = число в шапке списка групп | | |
| Заполняемость на главной («Как центр сегодня») | плитка «Заполняемость групп» на дашборде | Должны совпасть (с TRU-129 обе считают «дети / места») | | |

| Прогноз выручки | «Аналитика → Прогноз», главная карточка | Число или диапазон совпадают | | |
| Остатки занятий | Карточки детей против ручного пересчёта | На дашборде остатков нет; сверка — по `docs/mvp-acceptance.md`, раздел 1.1 (TRU-152) | | |

## 3. Права ролей (ТЗ п. 2, п. 11.7)

Войти под каждой ролью и открыть «Аналитика», любой отчёт и выгрузку.

| Роль | Ожидается | Результат | Замечание |
|---|---|---|---|
| Владелец | Все филиалы, все отчёты, выгрузка | | |
| Управляющий (закреплён за одним филиалом) | Только свой филиал; чужой филиал в адресе (`?branch=`) — «нет доступа» | | |
| Администратор | Раздела «Аналитика» нет, по прямой ссылке — нет доступа; на главной нет выручки | | |
| Администратор с настройкой «видит сводку» | Аналитика только по своему филиалу | | |
| Преподаватель | Ни аналитики, ни денег | | |
| Бухгалтер | Аналитики нет (деньги — в своих экранах) | | |

Внимание: управляющий без закреплённых филиалов видит всю организацию
(так устроены права во всей CRM) — перед демо проверить, что у каждого
управляющего True Ballet филиалы заданы. Вопрос — `project-status`, строка 31.
